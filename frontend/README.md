# About AI usage

I'm building this project that let me and my friends edit tags on my music server. Remotely, without any pain. I haven't found any good existing solutions, so I decided to build my own.

I'm learning C++ and I'm not a web-developer. I think building UI in C++ for web would be a bad idea, so I decided to make a web-app instead. But I don't know HTML/CSS/JS and so on, so I'm using AI to help me with that. 

In the future, I will add API documentation to let some of you build your own frontend that will probably be better than AI's one.
